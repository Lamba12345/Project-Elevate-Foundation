🔌 Spring Boot + SQLite Integration

This admin panel connects to the following REST API endpoints provided by the Spring Boot backend:

GET/api/contactsRetrieve all contact messages
POST/api/contactSave new contact message
GET/api/volunteersRetrieve all applications
POST/api/volunteerSave volunteer application
GET/api/donationsRetrieve all donations
POST/api/donateSave donation record
GET/api/newsletterRetrieve all subscribers
POST/api/newsletterSubscribe email

All data is persisted in SQLite via Spring Data JPA with Hibernate. See the backend/ folder for the Spring Boot project structure and database schema.
